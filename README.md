# azure-terraform-lab

A container platform on Azure. The third iteration of the same stack after GCP and AWS. The application is deliberately trivial. The question the repo answers is whether the pattern holds on a third provider, and what Azure does differently from the other two.

Region is uksouth. The subscription runs on trial credit with a spending limit, so resources stop rather than bill a card. The working pattern is build, capture evidence, destroy in the same session.

Status: in progress.
